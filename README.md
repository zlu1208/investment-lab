# Investment Lab

This project is a Next.js investment dashboard for tracking portfolio holdings, analyzing allocations, and viewing live quote data.

## Public access

The live site is available at:

https://investment-lab-phi.vercel.app/dashboard

## Accessing it on another device

1. Open the public URL on the other device.
2. If you want to share the exact portfolio data, open the Portfolio page and click "Copy Share Link".
3. Send that link to the other device and open it there.

## Local development

Run the development server:

```bash
npm run dev
```

Open http://localhost:3000 to view the app locally.

## Features

- Portfolio entry and editing
- Portfolio analysis and risk summary
- Live quote refresh for watchlist items
- Shareable portfolio links for cross-device access
